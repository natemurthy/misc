# mdp-cart-pole

The “Cart Pole” problem is a classic Markov decision process (MDP) for studying dynamical systems. It is a deceptively simple problem that dates back to the 1960s, grounded in the Bellman optimality equations but approached from different angles between two major research fields: optimal control theory and reinforcement learning.

These fields have recently converged in recognizing that model-predictive control (MPC) from the optimal control theory school is roughly equivalent to model-based reinforcement learning (MBRL) in the latter.

We use the "Cart Pole" problem to explore and understand the various implementations of solving this MDP over the last few decades to gain better insights into optimal control and RL.
